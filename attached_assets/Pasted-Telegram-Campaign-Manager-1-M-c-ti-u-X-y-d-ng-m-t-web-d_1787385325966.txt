Telegram Campaign Manager

1. Mục tiêu

Xây dựng một web dashboard quản lý tài khoản Telegram, nhóm/kênh và chiến dịch đăng bài theo lịch.

Hệ thống phải có giao diện hiện đại, responsive, dễ sử dụng trên điện thoại và máy tính.

Chỉ hỗ trợ các tài khoản Telegram và nhóm/kênh mà người dùng có quyền truy cập hoặc quản lý. Không xây dựng chức năng spam, gửi hàng loạt ngoài quyền hạn, né giới hạn Telegram, hoặc tự động tham gia nhóm.

⸻

2. Công nghệ

Ưu tiên stack:

* Frontend: Next.js + TypeScript
* UI: Tailwind CSS + shadcn/ui
* Backend: API routes/server actions của Next.js hoặc backend Node.js
* Database: PostgreSQL
* ORM: Prisma
* Queue/Scheduler: Redis + BullMQ nếu cần
* Telegram: thư viện MTProto tương thích Telegram API
* Authentication website: session/JWT an toàn
* Password/session/token phải được mã hóa khi lưu.

Nếu môi trường Replit không hỗ trợ một thành phần nào thì chọn giải pháp tương đương ổn định nhất.

16. Rate limit và an toàn

Thiết kế queue có giới hạn tốc độ hợp lý.

Không cố tình bypass Telegram rate limits.

Nếu Telegram trả về rate-limit/flood-wait:

* Đọc thời gian chờ được API trả về
* Đưa job về trạng thái delayed
* Retry sau thời gian được yêu cầu
* Không spam retry liên tục

Retry tối đa một số lần cấu hình được.

Ví dụ:

maxAttempts = 3

Sử dụng exponential backoff.

25. Quan trọng

Trước tiên hãy xây toàn bộ UI + database + authentication + campaign management.

Sau đó tích hợp Telegram API.

Không hardcode API credentials.

Nếu Telegram API chưa được cấu hình trong Replit, ứng dụng vẫn phải chạy được ở chế độ demo để tôi có thể xem toàn bộ giao diện.

Khi một phần Telegram API chưa hoạt động, hiển thị:

Telegram integration is not configured.
Configure TELEGRAM_API_ID and TELEGRAM_API_HASH to connect an account.

Không làm ứng dụng crash.
